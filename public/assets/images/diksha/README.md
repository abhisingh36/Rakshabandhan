# 📸 Diksha's Photos

Place your photos here:

```
public/assets/images/diksha/
  memory1.jpg   ← Caption: "That day was chaos 😂"
  memory2.jpg   ← Caption: "One of those random memories I'll always remember."
  memory3.jpg   ← Caption: "How did we even end up here? 😂"
  memory4.jpg   ← Caption: "Good times. ✨"
  memory5.jpg   ← Caption: "Okay I'm definitely keeping this one. 😌"
```

## Photo tips:
- Recommended size: 800×1000px (portrait) for best display in the memory card
- Any modern phone photo works (JPG/PNG)
- The card has a 4:5 aspect ratio — portraits look best
- Captions can be edited in: `src/data/config.js` → `memories` array

## If a photo is missing:
A warm placeholder card will appear instead of an error.
The experience will continue normally.
