# 📁 Audio Assets

Place your audio files here:

```
public/assets/audio/
  bgm.mp3        ← Background music (warm, soft, nostalgic loop)
  click.mp3      ← Soft UI button tap sound
  sparkle.mp3    ← Sparkle / magic sound (for gift opening)
  success.mp3    ← Correct quiz answer chime
  wrong.mp3      ← Wrong quiz answer (soft, not harsh)
  open.mp3       ← Gift opening whoosh sound
```

## Recommended free sources:

- **Freesound.org** — search "soft piano loop", "sparkle chime", etc.
- **Pixabay Music** — royalty-free, no attribution needed
- **Zapsplat.com** — free with account

## Notes:
- Keep bgm.mp3 under 3MB for fast loading
- Audio will not autoplay until Diksha taps "Let's go ✨"
- If files are missing, the experience continues silently (no crash)
